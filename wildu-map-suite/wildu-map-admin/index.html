Waypoints dell’area selezionata

Traccia GPX

I valori calcolati dal GPX sono solo una proposta: come admin puoi ritoccare manualmente km, dislivello e difficoltà prima di salvare. Se il GPX non contiene quote, compare un pulsante separato per stimare il dislivello da DEM.

Il file GPX viene caricato su Cloudflare R2 tramite Worker sicuro. Firestore salva solo metadati, URL pubblico e chiave oggetto.

Guida rapida

Incolla una Tile URL e usa “Autocompila”. Se il provider è riconosciuto, il sistema compila nome, attribution e zoom suggeriti. Se non è riconosciuto, non inventa dati: completa manualmente leggendo le condizioni del provider.

Non inserire secret key private. Sono accettabili solo URL o chiavi pubbliche pensate per frontend e protette da dominio/referrer.
