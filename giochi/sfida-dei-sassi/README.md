# Stone Lines — Skeleton Completo

Scheletro operativo per un gioco di logica 2D in browser, ispirato a Nim / Marienbad.

## Contenuto
- menu iniziale
- board renderizzato
- selezione contigua
- conferma mossa
- cambio turno
- modalità PvP e CPU semplice
- variante misère
- schermata finale

## Come provarlo
1. Apri `index.html` in browser.
2. Premi `Nuova partita`.
3. Clicca una pietra per iniziare una selezione.
4. Estendi la selezione cliccando altre pietre contigue della stessa riga.
5. Premi `Conferma`.

## Non incluso ancora
- CPU intelligente
- audio
- localStorage
- animazioni avanzate
- puzzle mode
